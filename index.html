PREFERÊNCIAS

Configurações

Gerencie os dados locais e consulte como adicionar suas aulas em MP3.

Adicionar aulas MP3

Coloque os arquivos na pasta correspondente dentro de aulas/ e cadastre seus metadados no arquivo script.js, na lista LESSONS. O caminho do áudio deve apontar para o arquivo real.

Exemplo: aulas/jung/inconsciente.mp3

Armazenamento

Esta versão guarda anotações, favoritos, playlists e progresso no armazenamento local do navegador deste dispositivo. Limpar os dados do navegador pode apagar essas informações.

Próxima integração

A arquitetura será conectada ao Supabase para autenticação, banco de dados, sincronização entre dispositivos e armazenamento de áudio. Nenhuma chave administrativa deve ser colocada no JavaScript público.
